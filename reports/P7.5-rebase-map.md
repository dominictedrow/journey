# P7.5 rebase map: the public 0.467 notebook (D-045)

Source: alexchilton/casmi26-lb-0-467-one-knob-rrf-offset-3-to-1 (Apache 2.0 notebook code). Local copy and extraction:
`data/kaggle/public/casmi26-lb-0-467-one-knob-rrf-offset-3-to-1/extracted/` (gitignored; read only, extracted with
`logs/s21_extract.py` / `logs/s21_frozen.py` via `ast`, nothing executed).

## Structure
1. **Wrapper** (51-line code.py, 5 cells). Writes 6 helper modules, decodes `frozen_0465.ipynb` from base64 (sha256-pinned),
   locates sanpier's model bundle by file hashes, installs the frozen notebook's RDKit wheel.
2. **Frozen 0.465 baseline** (`frozen/000..058`, ~3k lines). `runner.py` executes its cells in one scope. Stages:
   - EDA cells (Gluzdov data notebook, 002-020): mounts, pop prior tables.
   - Engine 2 (031-032): two-ranker engine (BIO + AFIX) in a subprocess, weighted RRF with the v4g list.
   - PubChem-only channel with popularity prior (033-034).
   - Engine 1 = Ahmed's v4n (035-039): FPNet A + engine FP bank, pool popularity rerank -> main lists.
   - ICEBERG + GLACIER simulators (040-041, 1.3k lines).
   - Gated PubChem merge (042-043), the same lever as our #8.
   - Two-engine fusion + simulator rerank (044-045, ALPHA 0.6, KRR 3).
   - Overlays (049-054): fragment score for molecules without simulator scores, rank-2 insertion of engine 2's top.
   - `export_evidence.py` then writes `frozen_candidate_evidence.parquet`: one row per final candidate
     (molecule_id, smiles, baseline_rank 1..25, processed, library_max, ice, gl, main/prefusion/engine2/pubchem ranks)
     and `effective_query_spectra.parquet` (the test rows used).
3. **Neural rerank** (0.465 -> 0.467). `neural_scores.py` scores each final candidate with sanpier's contrastive
   spectrum<->fingerprint model (`final_model.pt`, GPU). Score is cos/T + w*fp_match, averaged over every query spectrum.
   `submission.apply` reorders **within the same 25** by
   `1/(1+base_rank) + 0.25/(1+neural_rank)`. The candidate set is asserted unchanged.

## Where our pieces go
- **Lowest-risk insertion point: the final-25 rerank.** Our contrastive cos (np_p6_ft) and fragment `expl` are the same
  kind of per-candidate signal as sanpier's model. Add them as extra RRF channels:
  `1/(1+b) + 0.25/(1+r_sanpier) + w_ours/(1+r_ours)`. Inputs already exist (evidence parquet has SMILES, query
  parquet has spectra). Our encoder runs on CPU; reuse `casmi.kaggle.predict` featurisation + `casmi.rerank.fragment`.
  Ceiling: reorders only, adds no recall.
- **Later, higher ceiling:** feed our encoder's own candidate list as a third engine into the fusion (cell 045), or use
  our cos as an extra feature for the PubChem-only channel. These need edits inside the frozen notebook.

## Validation
- Their panel benchmark (`data/kaggle/public/panel/`, 250 Enveda timsTOF NP molecules, 89k main candidates keyed by
  InChIKey14, three hide-the-answer scenarios) is built for comparing ranking rules offline.
- **Caveat:** all 250 panel truths are in our data (149 train, 98 v_lib, 3 v_scaf; none in v_np), so our encoder has
  seen them. The public rankers saw them too. Panel differences are optimistic for both; the LB decides.
- Our V-np (196, held out from our encoder) can't be run through their pipeline locally (we don't execute public
  notebooks locally), so V-np only validates our channel's own ranking quality.
