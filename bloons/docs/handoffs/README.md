# Handoffs

One file per session: `NNN-YYYY-MM-DD.md`, numbered in order and append-only. The newest one together with `../START-HERE.md` is everything a new session needs.

## Template
```markdown
# Handoff NNN — YYYY-MM-DD

**Phase / step:** e.g. Phase 1 → step 1.3
**Session goal:** one line

## Done
- ...

## In progress (not finished)
- what, where it stopped, file:line if relevant

## Decisions made
- decision — why

## Blockers / open questions
- ...

## Files touched
- path — what changed

## Next action
One concrete task or command. Copied into START-HERE.md.
```
