## Done
- Read every `bloons/*.py` module and ran pyflakes, vulture and the offline suite (85 → 90 tests, all pass).
- **RoundTracker no longer needs the Auto Start setting.** It used to assume Auto Start was off unless `set_auto_start` was called, and Dom's setting is on, so `round_ended` would almost never fire. Now a round ends on the running → idle edge, or when the HUD round number goes up while the button shows a running round. The round of each running stretch is remembered, so each round fires once. The `auto_start` parameter is gone (callers updated: `scripts/watch_state.py`, tests).
- **`start_round()` reads the button before the guard.** Before, `round_active` from the last `observe()` could still be True after a round ended, and the guard refused with 'round_active'.
- **Abilities check "round only" against the live button** (`_sync_round` in `use_ability` / `use_ability_of`), not the stale `round_active`.
- **The hero earns round XP.** Before, `HeroRec.level` only changed through `buy_hero_level`, so the level, the abilities unlocked by levelling, and the level-up price were all frozen at level 1. `observe()` now calls `_hero_round_xp(r)` on each `round_ended` (`rules.hero_xp_for_round`, ×1 for Beginner maps). It levels the hero up and adds that level's abilities. This is an estimate; it isn't read off the screen.
- **`BarFilter` resets when ability slots shift** (a sold tower's slot goes away). Before, the per-slot history was applied to the wrong ability.
- Dead code removed: `Frame.bgra`, `rangecircle.to_units`, `harness.bar_reads`, a duplicate template cache in `state.py` (now uses `vision._templates`), a duplicate import in `_detector_towers` (`TOWER_SPRITE_PAD` is now a module constant), an unused Quartz import in `scripts/bench_capture_ocr.py`.
