## Done
- **Tiers with several abilities kept only the last one.** `_gain_ability` dropped the tower path's earlier abilities on every call, so Heli 0-4-0 ended up with only Support Drop (should be Redeploy + Support Drop), Heli 0-5-0 with 1 of 3 abilities, and Desperado tiers 4–5 with 1 of 2. `record_upgrade` now drops the path's abilities once, then adds every ability of the new tier (`replace=False`).
- **`rounds_done` on a round end uses the tracker's round number.** `RoundState.ended_round` (new field) is the round that ended, when the HUD was read. Before, the harness just added 1, so skipping mid-round observes left the count (and so the hero's XP round) wrong.
- **Money is accepted as soon as a spend or refund is confirmed.** New `HudFilter.accept()`; `_money_moved` calls it. Before, the guards kept the old money until two more HUD reads agreed, so the next action's affordability check was stale.
- **The money read before an action is protected against one misread.** New `_money_before()`: a raw read is used only if it agrees with the filtered value or with a second read; otherwise the filtered value. Before, one misread (`$1,357` → `$357`) made a real purchase look 'unconfirmed', and the tower went unregistered.
- `tools/play.py --hero` takes any unique part of a name, like the commands (it used to raise KeyError).
- 3 more regression tests; 93 pass, pyflakes clean.

## Decisions made
- When a tier repeats an ability (Take Aim at Desperado 3/4/5, Redeploy at Heli 4/5), it restarts on its full cooldown, the same as a new ability. Whether the game keeps the cooldown across that upgrade is unknown; the bar read corrects it either way.

## Blockers / open questions
- As in 045: the hero XP model isn't checked live; 'unconfirmed' can still mean the action happened.
- An ability slot's cooldown is set by the first instance gained (Redeploy is 45 s at 0-4-0, 15 s at 0-5-0).
- `set_targeting` covers registry towers only, not the hero.
- `parse_round` requires current ≤ total, so freeplay rounds (41/40) won't read, if the HUD shows them that way.
