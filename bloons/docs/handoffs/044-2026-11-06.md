## Decisions made
- The encoding only transforms fields (one-hot, flags, log scale, fractions). It doesn't weigh or pick features, because the model is Dom's (memory `rl-model-is-doms`). Everything is tunable in `obs.json`.
- One-hot lists are written out in `obs.json`, not read from `towers.json` at runtime. That way, a data change can't silently shift the layout; a test checks that the lists still match.
- The grid's path channel uses its own half-width, 4.5 units (the bloon band), not `path.half_width_units` (0.25, the placement keep-out pad). With 0.25 the channel came out almost empty.
- Grid box `[0.03, 0, 0.84, 1]` (the swept-mask area), 24 × 16 as PLAN's action-grid example. Cells are ~12 units wide, so placeable values are shares, not yes/no.
