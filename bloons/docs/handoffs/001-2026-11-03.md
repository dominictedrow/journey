## Decisions made
- **Game runs on a Mac; the harness runs in Python on that Mac.** Apple Arcade is Apple-only, and an iOS device can't be driven without a jailbreak or extra hardware.
- **Pixel-based harness** (capture + OCR + templates + CGEvent input). BTD6+ is a sandboxed App Store build, so mods and memory reading aren't possible.
- **Several maps from the start:** Monkey Meadow, Tree Stump, Town Center, Logs. Dom chose this.
- **Deterministic data tables** (rounds, costs, ranges) plus OCR cross-checks, instead of reading everything from pixels.
- **Macro-action Gymnasium env with action masking + MaskablePPO,** with a scripted baseline first. Real-time episodes make training expensive.
