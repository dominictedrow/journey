# Component build specs

Each component gets one file here, `NN_<component>.md`. It is written at the end of that phase's questioning session from Dom's answers in `docs/interrogation/`. Where they disagree, this file overrides `docs/spec/system_spec_v2.md`. Each file covers:

- purpose
- interfaces (inputs and outputs, table contracts)
- config keys and defaults
- algorithms
- tests
- acceptance criteria (the exit gate)
